# Diabetes Prediction using Machine Learning

A machine-learning project that predicts a diabetes class from eight clinical input features using a trained XGBoost model, a saved preprocessing scaler, and a Gradio web interface.

**Live demo:** [Try Diabetes Checker on Hugging Face Spaces](https://huggingface.co/spaces/NazmulNIR/Diabetes_Cheaker)

> **Disclaimer:** This project is for educational purposes only. It is not a medical device and must not be used to diagnose, treat, or make healthcare decisions.

## Overview

The application accepts eight features and passes them through the same saved scaler and trained model used by the project:

- Pregnancies
- Glucose
- Blood pressure
- Skin thickness
- Insulin
- Body mass index (BMI)
- Diabetes pedigree function
- Age

The app returns the model's predicted class and, when supported by the model, its estimated probability for the diabetes class. A model probability is not the same as a clinically validated risk estimate.

## Tech stack

- Python
- pandas and NumPy

## Project structure

```text
diabetes-prediction-ml/
├── app.py                 # Gradio interface and prediction function
├── requirements.txt       # Python dependencies
├── final_xgb_model.pkl    # Trained XGBoost model (add this file)
├── scaler.pkl             # Fitted preprocessing scaler (add this file)
├── README.md
└── .gitignore
```

The two `.pkl` files must be created from or downloaded from your own training workflow. The model and scaler must match the same feature order and preprocessing used during training.

## Run locally

### 1. Clone the repository

```bash
git clone https://github.com/SheikhNazmul/diabetes-prediction-ml.git
cd diabetes-prediction-ml
```

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.venv\\Scripts\\Activate.ps1
```

macOS/Linux:

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Add model artifacts

Place `final_xgb_model.pkl` and `scaler.pkl` in the project root. Do not use a scaler from a different training run or change the feature order.

### 5. Start the app

```bash
python app.py
```

Open the local Gradio URL printed in the terminal.
